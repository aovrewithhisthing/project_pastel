# Chronicle & Seal — Kapsul Dimsum Digital

Next.js 16 + Tailwind v4 • LocalStorage mock • Premium parchment aesthetic

## Jalankan
```bash
npm install
npm run dev # http://localhost:3000
```

## Routes
- `/` Beranda — hero + countdown live
- `/vault` Vault & Arsip — filter, search, timeline
- `/tulis` Tulis Kapsul — validasi + segel AES-256 mock
- `/capsule/[id]` Buka Segel — wax-melt + refleksi Now vs Then
